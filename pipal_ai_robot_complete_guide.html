Build guide — 10 steps

1

Assemble the 2WD chassis

Screw the two TT gear motors into the motor mount brackets on the chassis plate. Push rubber wheels onto the motor axles. Attach the caster wheel to the front-bottom hole. All screws and standoffs come with the kit — takes about 15 minutes.

2

Solder header pins onto RPi Zero 2W

The Pi Zero 2W ships without headers. Solder the 40-pin male header strip onto the GPIO holes — this is the trickiest step. Use a 30W iron, flux, and fine solder. Watch a "soldering RPi Zero headers" tutorial on YouTube before starting if you're new to it. Take your time on each pin.

3

Mount RPi Zero 2W and L298N on chassis

Use M2.5 plastic standoffs (or double-sided foam tape as a beginner alternative) to mount the RPi and the L298N board on the chassis plate. Keep them side by side to keep wires short. The L298N goes near the motors; RPi can sit on top.

4

Connect motors to L298N

Left motor wires → L298N OUT1 and OUT2. Right motor wires → OUT3 and OUT4. Which wire goes to which terminal determines forward/reverse direction — you can swap them later in software if the robot goes the wrong way.

5

Wire L298N to RPi GPIO

Using male-to-female jumper wires: IN1 → GPIO18, IN2 → GPIO23, IN3 → GPIO24, IN4 → GPIO25. Connect L298N GND to RPi GND (Pin 6). Connect L298N +5V logic pin to RPi 5V (Pin 2).

6

Connect the OLED display (I2C)

Wire OLED VCC → RPi 3.3V (Pin 1), GND → GND, SDA → GPIO2 (Pin 3), SCL → GPIO3 (Pin 5). After software setup, verify with i2cdetect -y 1 — you should see address 0x3C in the grid.

7

Set up the USB audio chain

Plug the micro USB OTG hub into the RPi's data USB port. Plug in the USB sound card and USB microphone into the hub. Audio chain: sound card LINE OUT → PAM8403 IN+/IN− → speaker terminals. Power the PAM8403 from RPi 5V and GND. Use the PAM8403 trimmer pot to adjust volume.

8

Wire the wake button

Connect one leg of the push button to GPIO17 (Pin 11) and the other to any GND pin. No resistor needed — the code enables RPi's internal pull-up resistor. Pressing the button is how you wake PiPal and start a conversation.

9

Set up battery power

Wire battery holder + to LM2596 Vin+ and also directly to L298N motor power terminal. Wire − to LM2596 Vin− and L298N GND. Adjust the LM2596 trimmer until a multimeter reads exactly 5.0V on the output, then connect to RPi 5V pin. Never power RPi from USB and battery at the same time.

10

Flash, install software, and run

Flash Raspberry Pi OS Lite to the microSD, SSH in, run the install commands (see Code + Setup tab), add your Claude API key, upload pipal_main.py, and run it. Press the button, say hello, and PiPal will talk back and move!

Code + software setup

Step 1 — Flash Raspberry Pi OS Lite:

Use Raspberry Pi Imager (free, raspberrypi.com). Choose Raspberry Pi OS Lite 64-bit. In Advanced Settings, pre-configure your WiFi SSID/password and enable SSH before flashing.

Step 2 — First boot (SSH in as pi@raspberrypi.local):

sudo raspi-config
# Go to: Interface Options → I2C → Enable → Yes
# Then: Finish → Reboot

sudo apt update && sudo apt upgrade -y
sudo apt install -y python3-pip espeak python3-pyaudio i2c-tools portaudio19-dev

Step 3 — Install Python libraries:

pip3 install anthropic SpeechRecognition luma.oled Pillow --break-system-packages

# Verify OLED is wired correctly:
i2cdetect -y 1    # Should show 0x3C in the output grid

# Find your USB microphone device index:
python3 -c "import speech_recognition as sr; print(sr.Microphone.list_microphone_names())"

Step 4 — Set your Claude API key:

echo 'export ANTHROPIC_API_KEY="sk-ant-your-key-here"' >> ~/.bashrc
source ~/.bashrc
# Get your free API key at: console.anthropic.com

Step 5 — Upload and run PiPal:

# Copy pipal_main.py from your computer to the RPi:
scp pipal_main.py pi@raspberrypi.local:~/

# Run it!
python3 ~/pipal_main.py

# Optional: auto-start on every boot
(crontab -l; echo "@reboot sleep 20 && python3 /home/pi/pipal_main.py") | crontab -
Running cost: Claude Haiku costs ~$0.00025 per 1K input tokens. At 50 conversations/day of ~200 tokens each, that works out to roughly ₹1–2 per day — effectively free.
